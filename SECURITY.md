# Безопасность

## Сообщить о проблеме

Не публикуй секреты или подробности эксплуатации в обычном issue. Если на странице Security репозитория включена функция **Report a vulnerability**, используй её для приватного сообщения. Если её нет, создай issue с просьбой предоставить приватный канал, без деталей и конфигураций. Срок ответа и отдельные поддерживаемые ветки пока не установлены; исправления выходят в основной ветке.

## Что считается секретом

- Reality/WireGuard privateKey и presharedKey, SSH-ключи и токены Telegram.
- VLESS-ссылки и QR-коды: UUID в них даёт доступ к серверу.
- URL подписки, содержимое подписки, реальные клиентские/серверные конфиги и резервные копии.
- Корпоративные маршруты, внутренние DNS и адреса — потенциально конфиденциальные данные, даже без ключей.

`.gitignore` и Gitleaks снижают риск случайной публикации, но не гарантируют отсутствие секретов. Игнорирование не удаляет файлы из истории. Для релиза используй Git-архив проверенного коммита, а не архив рабочей директории.

При утечке сначала отзови доступ: замени UUID клиента, приватный ключ Reality и shortId, токен бота или секрет подписки — в зависимости от того, что утекло. Затем обнови клиентов и проверь соединение. Очистка Git-истории не заменяет ротацию; её нужно согласовать с участниками, поскольку она меняет идентификаторы коммитов.

## Границы доверия

Бот предназначен для администратора сервера. Каждый разрешённый чат получает административные команды, ссылки пользователей и доступ к диагностике. При добавлении группы **все её участники** получают эти возможности; рекомендуются личные чаты. Сообщения и QR проходят через Telegram.

Процесс бота работает без root, но имеет sudo-доступ к фиксированным операциям `vpnctl.sh`, чтение конфигурации Xray и журналов через `systemd-journal`. Это не изоляция между недоверенными арендаторами. Stats API слушает loopback, но доступен другим локальным процессам. Не выдавай посторонним shell-доступ на этот VPS.

Примеры используют `config.json`, доступный на чтение сервису и боту. Для многопользовательского сервера отдельно настрой группу/ACL и проверь права Xray и бота; не меняй права вслепую на 600, иначе сервис может перестать читать конфиг.

Квоты используются для уведомлений, а не автоматического ограничения трафика. Учёт по Stats API не является биллинговой системой: несобранные счётчики теряются при рестарте; сбой между сбросом счётчиков и записью на диск тоже может потерять дельту. Сверяй расход с данными провайдера.

Списки маршрутизации, установщик Xray и другие загружаемые ресурсы — отдельные зависимости. Проверь источник и версию; сохраняй проверенную версию перед обновлением. Автоматические тесты репозитория не проверяют доступность внешних сайтов и устойчивость к блокировкам.
